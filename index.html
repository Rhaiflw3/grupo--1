🎯 Objetivo

Organizar y gestionar de manera eficiente la información relacionada con los alumnos, docentes, asignaturas y la carga académica, estableciendo relaciones claras entre los procesos educativos[cite: 5, 6].

🛠️ Herramienta

Se utilizó Power Pivot para modelar las relaciones entre las entidades y asegurar la integridad de los datos académicos.

📊 Sistema de Calificación

El sistema calcula automáticamente el promedio basado en tres aportes parciales[cite: 16].

Ejemplo de Cálculo:
Aporte 1 (15) + Aporte 2 (14) + Aporte 3 (10)
= Promedio (13)

🚀 Conclusiones y Sugerencias

El sistema demostró que una correcta estructuración de datos evita errores y mejora el acceso a la información[cite: 21]. Para el futuro se sugiere:

  • Implementación Real: Desplegar en un entorno real para validar efectividad[cite: 22].
  • Seguridad: Protocolos de respaldo para proteger datos personales[cite: 23].
  • Capacitación: Entrenar a administrativos y docentes en el uso del sistema[cite: 24].
  • Módulos Extra: Añadir generación de reportes automáticos y consultas en línea[cite: 26].
